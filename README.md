# 🌤️ Application Météo – HTML/CSS/JS

Cette application affiche la météo actuelle d'une ville grâce à l'API OpenWeatherMap. Elle utilise JavaScript pour interroger l’API, et HTML/CSS pour afficher les données de manière esthétique

## 🧰 Technologies utilisées

- HTML5 : structure de la page
- CSS3 : mise en forme responsive
- JavaScript (ES6) : logique d'appel à l'API + interactions
- OpenWeatherMap API : récupération des données météo

## ▶️ Comment l'utiliser

1. Télécharge ou clone ce projet :

        git clone https://github.com/bryanTRX/Meteo.git 

2. Ouvre simplement le fichier index.html dans un navigateur.

3. Sinon, vous pouvez également utiliser ce lien vers la version déployée que j’ai réalisée grâce à GitHub Pages :

        https://bryantrx.github.io/Meteo/

Inspiré des exemples de projets météo modernes avec HTML/CSS/JS.
