# 🌤️ Application Météo – HTML/CSS/JS

Cette application affiche la météo actuelle d'une ville grâce à l'API OpenWeatherMap. Elle utilise JavaScript pour interroger l’API, et HTML/CSS pour afficher les données de manière esthétique

## 🧰 Technologies utilisées

- HTML5 : structure de la page
- CSS3 : mise en forme responsive
- JavaScript (ES6) : logique d'appel à l'API + interactions
- OpenWeatherMap API : récupération des données météo
